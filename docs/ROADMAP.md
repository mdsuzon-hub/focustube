# Prioritised future enhancements

1. Real-browser regression suite against recorded YouTube DOM snapshots (selector drift is the main maintenance risk).
2. Localised Shorts/tab label detection.
3. Reordering search results by relevance (opt-in), and a score explainer.
4. Optional YouTube Data API adapter (own credentials, quota tracking, policy review) for durations/metadata and playlist import.
5. Drag-and-drop queue reordering (keyboard buttons exist today).
6. Notes/timestamps per queued video.
7. Auto-advance to the next queued video.
8. Per-topic goals and weekly review summary.
9. Firefox support (MV3 differences).
10. Sync of settings across devices via `chrome.storage.sync` (opt-in).
