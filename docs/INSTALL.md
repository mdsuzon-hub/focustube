# Install (unpacked)

1. `npm install && npm run build` (or use the prebuilt `dist/` / `focustube.zip`; unzip it first).
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and choose the `dist/` folder.
4. Pin FocusTube from the puzzle-piece menu, open youtube.com and click the icon.
5. After code changes run `npm run build` and press the reload icon on the extension card, then refresh YouTube tabs.

Requires Chrome 110+.
